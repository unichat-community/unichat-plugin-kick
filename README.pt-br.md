# UniChat Plugin - Kick Integration

[🇺🇸 English](./README.md) | [🇧🇷 Português](./README.pt-br.md)

Este plugin foi separado do repositório principal do [**UniChat**](https://codeberg.org/unichat/unichat) para melhorar a modularidade e permitir que os usuários escolham qual widget desejam usar.

Eventos do scraper do Kick:
- RemoveMessage
- RemoveAuthor
- Message
